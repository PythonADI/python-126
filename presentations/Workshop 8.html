Don’t write it
if it exists.

Need a square root? A random number? Today’s date? Someone already wrote that — and it ships inside Python. A module is a bundle of ready-made code you pull in with import.

Python’s “standard library” is hundreds of these — batteries included. And any .py file you write is a module too.

[ PART 1 · SAVE A DICT ]
08

Save a whole dictionary.

Last week you wrote files line by line. json saves an entire dictionary at once — and loads it back as a real dict.

import json profile = {"name": "nino", "age": 21} with open("profile.json", "w") as f: json.dump(profile, f) # dict → file with open("profile.json") as f: data = json.load(f) # file → dict print(data["name"]) # nino

json.dump writes, json.load reads. The thing that comes back is an ordinary dictionary — index it just like always.

[ PART 2 · WHY ]
10

A dict, leveled up.

A dictionary groups data. A class groups data and the functions that work on it — and lets you stamp out many copies from one blueprint.

Dictionary
dog = { "name": "Rex", "age": 3, } # data only
Class → object
rex = Dog("Rex", 3) rex.bark() # data + behaviour # a reusable blueprint

class = the blueprint (a Dog in general). object = one thing built from it (this specific dog).

Python · Workshop 08blueprint vs object
[ PART 2 · ANATOMY ]
11

Inside a class.

Three parts: the blueprint, the setup, and the behaviour.

class Dog: # the blueprint def __init__(self, name, age): # runs when a Dog is made self.name = name # store data on the object self.age = age def bark(self): # a method (behaviour) return f"{self.name} says woof!"

__init__ is the setup — it builds the object. Lines like self.name = name are attributes (data). bark is a method (a function that belongs to the class).

[ PART 2 · WHAT IS SELF ]
14

“self” is this one.

self is the particular object a method was called on. When you write rex.bark(), Python quietly passes rex in as self.

rex.bark() # you write this # Python runs: Dog.bark(rex) # so inside bark, self IS rex

That’s why every method’s first parameter is self, and why we say self.name — “this object’s name.” You never pass it by hand; the dot does it for you.

An object that guards itself.
