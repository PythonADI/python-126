[ PART 1 · DUNDER METHODS ]
04

The “dunder” family.

Names wrapped in double underscores. Python calls them for you at the right moment — you never call them by name.

__init__
Build it
Runs when you make the object. Dog("Rex", 3). You met this last week.
__str__
Print it
The friendly text for print(obj) and str(obj).
__repr__
Debug it
The exact text for the REPL and inside [lists].
__eq__
Compare it
Decide when a == b is True for your type.

There are many more (__len__, __lt__, …) — but these four carry you a long way. Each one returns its answer.

08

Don’t repeat yourself.

Dogs, cats and cows all have a name. Copy that into three classes? No — write it once in a parent and let the others inherit it.

Repeated
class Dog: def __init__(self, name): self.name = name class Cat: def __init__(self, name): self.name = name # ...again, and again
Inherited
class Animal: def __init__(self, name): self.name = name class Dog(Animal): ... class Cat(Animal): ...

class Dog(Animal) means “a Dog is an Animal” — it gets everything Animal has, for free.

Which speak() runs?

A subclass can override a method. If it doesn’t, it falls back to the parent’s. Step through the loop:

class Animal: def speak(self): return f"{self.name} makes a sound"class Dog(Animal): def speak(self): return f"{self.name} says woof"class Cat(Animal): def speak(self): return f"{self.name} says meow"class Cow(Animal): pass print(Dog("Rex").speak())print(Cat("Felix").speak())print(Cow("Daisy").speak())

Dog and Cat override speak; Cow has none, so Python walks up to Animal for its version. That fallback is inheritance.

Let the parent set up first.

A method you use like data.

Some values are computed, not stored. @property lets you read c.area with no parentheses. Step through it:

class Circle: def __init__(self, radius): self.radius = radius @property def area(self): return math.pi * self.radius * self.radius c = Circle(5)print(c.area)  # no () — like an attributec.radius = 10  # recomputes
radius = 510

No stored area to keep in sync — it’s worked out fresh each time you ask. Change the radius, and the area follows on its own.
