[ PART 1 · DUNDER METHODS ]
07

The “dunder” family.

Names wrapped in double underscores. Python calls them for you at the right moment — you never call them by name.

__init__
Build it
Runs when you make the object. Dog("Rex", 3). You met this last week.
__str__
Print it
The friendly text for print(obj) and str(obj).
__repr__
Debug it
The exact text for the REPL and inside [lists].
__eq__
Compare it
Decide when a == b is True for your type.

There are many more (__len__, __lt__, …) — but these four carry you a long way. Each one returns its answer.

11

Don’t repeat yourself.

Dogs, cats and cows all have a name. Copy that into three classes? No — write it once in a parent and let the others inherit it.

Repeated
class Dog: def __init__(self, name): self.name = name class Cat: def __init__(self, name): self.name = name # ...again, and again
Inherited
class Animal: def __init__(self, name): self.name = name class Dog(Animal): ... class Cat(Animal): ...

class Dog(Animal) means “a Dog is an Animal” — it gets everything Animal has, for free.
