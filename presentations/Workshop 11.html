[ PART 1 · HTTP ]
03

It’s all just text.

No magic anywhere. The request and the response are two short text messages in a format called HTTP. Step through them:

The request — what the browser sends
GET /menu/ HTTP/1.1Host: cafe.ge
The response — what the server sends back
HTTP/1.1 200 OKContent-Type: text/html <h1>Cafe Tbilisi</h1><p>khachapuri — 12₾</p>
0 / 3

The body of the response is HTML — the language of page structure. The browser reads the tags and draws them: <h1> becomes a big heading, <p> a paragraph, <li> a bullet.

08

A web page is a function.

Request in, response out — a view is a plain Python function, and urls.py wires an address to it. Step through one visit:

# mysite/urls.py — the address bookurlpatterns = [path("", views.home)] # pages/views.py — the pages themselvesfrom django.http import HttpResponse def home(request): return HttpResponse("<h1>gamarjoba!</h1>")
http://127.0.0.1:8000/
gamarjoba!
0 / 4

That is the whole trick: path("") is the home address, home is a function like any you wrote in Workshop 4 — it just returns HTML instead of a number.

[ PART 2 · URL PARAMETERS ]
09

The URL fills the argument.

One view, endless pages. <str:name> captures a piece of the address and hands it to your function. Click a request:

# mysite/urls.pypath("hello/<str:name>/", views.hello) # pages/views.pydef hello(request, name): return HttpResponse(f"<h1>გამარჯობა, {name}!</h1>")
http://127.0.0.1:8000/
click a request below…
click →

You wrote hello once. Django reads the address, plucks out the name, and calls hello(request, name="nino") — an f-string does the rest.

[ PART 2 · TEMPLATES ]
10

HTML with holes.

Real pages don’t live inside Python strings. A template is an HTML file with {{ holes }}; render() fills them from a dict. Step through it:

# pages/views.pydef menu(request): context = { "cafe": "Cafe Tbilisi", "dishes": ["khachapuri", "khinkali"], } return render(request, "menu.html", context)
<!-- pages/templates/menu.html --><h1>{{ cafe }}</h1><ul>{% for dish in dishes %} …</ul>
http://127.0.0.1:8000/menu/
Cafe Tbilisi
  • khachapuri
  • khinkali
0 / 3

Python gathers the data; the template owns the look. The dict’s keys become the template’s variable names.
